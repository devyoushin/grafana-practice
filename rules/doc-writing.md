# 문서 작성 규칙 — grafana-practice

## 기본 원칙
1. 모든 문서는 한국어로 작성하되, 기술 용어(Dashboard, Panel, Datasource, Alerting 등)는 영어 그대로 사용
2. 제목은 `# [주제] — Grafana [문서유형]` 형식으로 통일
3. 문서 상단에 작성일, 작성자, 검토자 메타데이터 포함
4. 코드 블록에는 반드시 언어 지정 (```json, ```yaml, ```bash)
5. 대시보드 문서에는 패널별 설명 테이블 포함

## 문서 구조
- **개요**: 목적과 대상 사용자 (3-5문장)
- **대시보드 구성**: 패널 목록 및 설명
- **운영**: 핵심 명령어 및 체크리스트
- **트러블슈팅**: 증상-원인-해결 테이블
- **참고**: 관련 대시보드 및 문서 링크

## 대시보드 문서화 규칙
- 각 패널의 목적과 임계값 설명
- 변수(Variables) 사용법 명시
- 대시보드 UID 및 provisioning 경로 기록
- 스크린샷 또는 JSON 모델 링크 포함

## 알림 문서화 규칙
- 알림 조건을 한국어로 풀어서 설명
- 예상 원인 목록 제공
- 처음 대응하는 사람도 이해할 수 있는 수준

## 금지 사항
- 개인 식별 정보 포함 금지
- 프로덕션 자격증명 문서에 포함 금지
- 검증되지 않은 대시보드 JSON 문서화 금지
