# Grafana Docs

Grafana 문서는 학습 문서, 규칙, 템플릿, 에이전트 프롬프트를 함께 관리합니다.

| 폴더/문서 | 내용 |
|------|------|
| `install.md` | Helm, systemd, Docker Compose 설치 |
| `datasource-guide.md` | Prometheus/Mimir, Loki, Tempo 데이터소스 |
| `dashboard-guide.md`, `dashboard-design-guide.md` | 대시보드 생성과 설계 원칙 |
| `variable-guide.md` | 템플릿 변수와 동적 대시보드 |
| `explore-guide.md` | Explore 기반 PromQL/LogQL 분석 |
| `alerting-guide.md` | Grafana Alerting 구성 |
| `provisioning-guide.md` | 데이터소스와 대시보드 GitOps 관리 |
| `slo-guide.md`, `oncall-runbook.md` | SLO와 온콜 운영 |
| `rules/` | 문서 작성 및 운영 규칙 |
| `templates/` | 서비스 문서, 런북, 장애 보고서 템플릿 |
| `agents/` | Claude 에이전트 프롬프트 |

처음 읽을 문서는 `install.md`입니다.
