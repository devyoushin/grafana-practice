# AI 작업 지침

이 디렉터리는 Grafana 문서를 다룰 때 사용하는 AI 작업 지침을 모은다.

## 문서 목록

| 문서 | 용도 |
|------|------|
| `doc-writer.md` | 문서 작성 기준 |
| `dashboard-designer.md` | 대시보드 설계 기준 |
| `alerting-advisor.md` | 알림과 라우팅 설계 |
| `troubleshooter.md` | 문제 해결 절차 |

## 언제 보나

- 새 문서를 쓸 때 `doc-writer.md`
- 대시보드 레이아웃과 UX를 설계할 때 `dashboard-designer.md`
- Alerting을 설계할 때 `alerting-advisor.md`
- 성능/장애 분석이 필요할 때 `troubleshooter.md`
